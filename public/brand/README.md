# LifePilot brand assets

`lifepilot-symbol.png` and `lifepilot-logo.png` are the original images supplied by the team, copied without pixel changes.

`src/components/brand-art.tsx` uses the symbol and the original lettering through SVG luminance masks. Only the viewport crops the surrounding black margins; CSS controls the visible colour. Use `Brand` for the horizontal name and symbol, and `BrandArt` for the standalone symbol. Do not replace the lettering with a typeface or a similar icon.

The UI uses forest green `#2e4e38` on light surfaces, pale green `#d4e5b7` on dark surfaces, sage panels `#dfe9ce`, and a warm off-white background `#f6f5ef`. The original white-on-black symbol is also the browser and touch icon.
